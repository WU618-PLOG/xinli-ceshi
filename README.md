# 心理测试小站

三份轻量心理自测,纯静态单文件页面,无外部依赖、可离线运行。

## 包含的测试

| 页面 | 内容 | 题量 |
| --- | --- | --- |
| bigfive.html | 大五人格测试(外向性 / 宜人性 / 尽责性 / 情绪稳定性 / 开放性) | 50 题 |
| mood.html | 情绪状态自查(焦虑 GAD-7 + 抑郁 PHQ-9) | 16 题 |
| attachment.html | 亲密关系依恋类型测试(安全型 / 焦虑型 / 回避型 / 紊乱型) | 24 题 |

首页 index.html 为导航页,点击卡片进入对应测试。

## 题目来源与版权

- 大五人格:IPIP 公开题库(Public Domain)
- 情绪自查:GAD-7 / PHQ-9(公开发布的公有领域量表)
- 依恋测试:基于依恋理论原创编写
