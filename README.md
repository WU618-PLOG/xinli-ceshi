# 心理测试小站

十款轻量心理自测,纯静态单文件页面,无外部依赖、可离线运行。

## 包含的测试

| 页面 | 内容 | 题量 |
| --- | --- | --- |
| bigfive.html | 大五人格测试(外向性 / 宜人性 / 尽责性 / 情绪稳定性 / 开放性) | 50 题 |
| mood.html | 情绪状态自查(焦虑 GAD-7 + 抑郁 PHQ-9) | 16 题 |
| attachment.html | 亲密关系依恋类型测试(安全型 / 焦虑型 / 回避型 / 紊乱型) | 24 题 |
| konan.html | 名侦探柯南角色性格测试(8 位角色匹配) | 20 题 |
| xiyou.html | 西游记角色性格测试(8 位角色匹配) | 18 题 |
| fun.html | 精神状态大赏(12 种魔性鉴定,搞笑款) | 16 题 |
| mask.html | 社会面具测试(面具厚度 + 4 种面具类型) | 20 题 |
| gender.html | 心理性别构成测试(双性化 / 阳刚主导 / 阴柔主导 / 未分化) | 20 题 |
| neihao.html | 精神内耗指数测试(反刍 / 纠结 / 讨好 / 完美四大耗电源) | 20 题 |
| pleaser.html | 讨好型人格测试(拒绝困难 / 需求后置 / 过度道歉 / 认同饥渴) | 20 题 |

首页 index.html 为导航页,点击卡片进入对应测试。

## 题目来源与版权

- 大五人格:IPIP 公开题库(Public Domain)
- 情绪自查:GAD-7 / PHQ-9(公开发布的公有领域量表)
- 依恋 / 面具 / 心理性别 / 内耗 / 讨好测试:基于心理学理论(依恋理论、荣格 Persona、Bem 双性化理论等)原创编写
- 柯南 / 西游记角色测试:粉丝向趣味演绎,相关角色版权归原著方所有
- 精神状态大赏:纯原创娱乐内容

## 免责声明

所有测试仅供自我了解参考,不构成医学或心理诊断依据。
